# 📊 Customer Churn Prediction

A machine learning project to analyze customer behavior and predict churn using Python, Pandas, and Scikit‑Learn.  
This project is part of my data science portfolio, showcasing skills in data cleaning, EDA, feature engineering, and model building.

---

## 🔍 Project Overview

Customer churn is one of the biggest challenges for subscription‑based businesses.  
The goal of this project is to:

- Understand why customers leave  
- Identify patterns in customer behavior  
- Build a predictive model to classify customers as “likely to churn” or “not likely to churn”  
- Provide actionable insights for retention strategies
